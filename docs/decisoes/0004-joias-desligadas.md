# 0004 — Joias desligadas até prova

Cada linha do chat existe em 5 a 11 cópias que mudam de lugar e não tem horário. Contar "texto novo" deu
1.483 joias num dia. O parser já reconhece as linhas (incluindo "Fortuna do Imperador"), mas o painel mostra
"em calibração". Só liga na fase 6 se o `zen-diag listachat` achar a lista ORDENADA do chat e a contagem
pela posição bater com uma contagem manual.
